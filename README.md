# 복약 다이어리

매일 먹는 약의 **복용 루틴**(기간별 알 수)을 등록해 두면 그날 몇 알 먹을지 알려 주고,
복용 체크와 그날의 느낌·부작용 메모를 달력으로 모아 보는 아이폰용 웹앱(PWA)입니다.
서버 없이 HTML·CSS·JavaScript 파일만으로 돌아가고, 기록은 휴대폰 안에만 저장됩니다.

## 왜 웹앱(PWA)으로 시작했나

| | 아이폰 네이티브 앱 | 웹앱 (PWA) ← 지금 |
|---|---|---|
| 필요한 것 | Mac + Xcode, Apple 개발자 계정(연 $99) | 브라우저만 |
| 설치 | App Store 또는 TestFlight | Safari → 공유 → **홈 화면에 추가** |
| 고치기 | 다시 빌드해서 설치 | 파일 고쳐서 올리면 끝 |
| 정해진 시간 알림 | 쉬움 | 서버가 필요해서 어려움 (아래 *알림* 참고) |

혼자 쓰는 기록 앱은 웹앱으로 먼저 만들어 써 보고, 정말 필요해지면 그때 네이티브로 옮기는 편이 빠릅니다.

## 기능

- **약 설정** (처음 화면): 약 이름, 용량, 복용 시작일, 단계별 루틴
  - 예) `1단계 14일 동안 하루 1알` → `2단계 2주 동안 하루 2알`
  - 쉬는 기간은 0알로 적으면 됩니다 (예: 3주 복용, 1주 휴약).
  - 루틴이 끝나면: 마지막 개수로 계속 / 복용 종료 / 1단계부터 반복
  - 입력하는 동안 날짜별 일정을 미리 보여 줍니다.
- **오늘**: 약마다 오늘 먹을 알 수, 지금 몇 단계인지, 다음에 알 수가 바뀌는 날
  - `복용 기록하기` → **"아침약 2알 드셨나요?" 예 / 아니오** 로 한 번 더 확인
  - 기록 취소도 예 / 아니오 확인을 거칩니다.
  - 모든 약을 기록하면 "오늘치 약 복용 완료"로 바뀝니다.
  - 오늘의 메모 칸: 쓰는 대로 자동 저장
- **달력**: 날짜 색으로 복용 상태 표시 (초록 완료 · 노랑 일부 · 분홍 미복용 · 점 메모)
  - 위쪽에 총 복용 기간과 오늘이 며칠째인지 표시
  - 날짜를 누르면 그날 약별 복용 여부와 메모가 나오고, 지난 날짜도 늦게 기록하거나 메모를 쓸 수 있습니다.
- **메모**: 날짜별 메모만 모아 보기, 검색
- **보내기**: 기간을 골라 약 루틴 + 날짜별 복용 + 메모를 글로 정리해서
  공유(메일·카카오톡 등) / 메일 앱 / 복사 / 텍스트 파일 저장
- **백업**: 전체 기록을 JSON 파일로 저장하고 다시 불러오기

## 아이폰에서 쓰기

1. 앱 파일을 인터넷 주소로 올립니다. 가장 쉬운 방법은 **GitHub Pages** 입니다.
   - 저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정합니다.
   - 1~2분 뒤 `https://fist-ban.github.io/med-diary/` 에서 열립니다.
   - 공개되는 것은 앱 코드뿐이고, 복용 기록과 메모는 각자의 휴대폰에만 저장돼 어디에도 올라가지 않습니다.
2. 아이폰 **Safari**로 그 주소를 엽니다.
3. 아래쪽 **공유 버튼 → 홈 화면에 추가**를 누릅니다.
4. 이제 홈 화면 아이콘으로 열면 주소창 없이 앱처럼 열리고, 인터넷이 없어도 열립니다.

> 💾 **데이터 보관 주의**: 기록은 이 휴대폰의 이 앱 안에만 있습니다.
> Safari 탭으로만 쓰면 오래 안 열었을 때 iOS가 데이터를 지울 수 있으니 꼭 **홈 화면에 추가해서** 쓰고,
> 가끔 `보내기 → 백업 파일 저장`으로 백업해 두세요. 폰을 바꿀 때도 이 백업 파일로 옮깁니다.

## 매일 알림 받기 (지금 할 수 있는 방법)

웹앱이 정해진 시간에 알림을 보내려면 푸시 서버가 필요해서, 이번 버전에는 넣지 않았습니다.
대신 아이폰 기본 기능으로 충분히 대신할 수 있어요.

- **미리 알림** 앱에 "약 먹고 복약 다이어리 체크" 를 매일 반복으로 만들어 두고, 알림이 오면 홈 화면 아이콘으로 앱을 엽니다.
- ⚠️ 단축어의 `URL 열기`로 앱 주소를 열면 홈 화면 앱이 아니라 **Safari**에서 열립니다.
  아이폰은 홈 화면 앱과 Safari의 저장 공간이 따로라서, 그쪽에는 기록이 비어 보이니 쓰지 마세요.

## 파일 구성

```
├── index.html            화면 틀, 아래 탭
├── style.css             디자인 (밝은/어두운 모드)
├── schedule.js           날짜·루틴·요약 계산 (화면과 무관, 테스트 대상)
├── app.js                화면 그리기, 버튼 동작, 저장
├── sw.js                 오프라인용 캐시 (서비스 워커)
├── manifest.webmanifest  홈 화면 앱 설정
├── icon-*.png            앱 아이콘
└── tests/schedule.test.js
```

제목과 숫자는 Google Fonts의 둥근 글꼴 **Jua**를 씁니다. 처음 열 때 한 번 받아 두고(서비스 워커가 보관) 이후에는 오프라인에서도 같은 모양으로 보이며, 받지 못하면 기본 글꼴로 보입니다.

데이터는 브라우저 `localStorage`의 `med-diary:v1` 한 칸에 이런 모양으로 저장됩니다.

```js
{
  meds: [{ id, name, dose, startDate: '2026-10-01',
           phases: [{ length: 14, unit: 'day', pills: 1 }, { length: 2, unit: 'week', pills: 2 }],
           after: 'continue' }],          // 'continue' | 'stop' | 'repeat'
  logs:  { '2026-10-08': { [약 id]: { pills: 2, at: '기록한 시각' } } },
  memos: { '2026-10-08': { text: '오전에 조금 졸림', updatedAt: '...' } },
  settings: { email: '' }
}
```

## 컴퓨터에서 실행·테스트

```bash
# 계산 로직 테스트 (Node 22 이상)
node --test tests/*.test.js

# 컴퓨터 브라우저로 열어 보기 (http://localhost:8000)
python3 -m http.server 8000
```

`index.html`을 파일로 바로 열어도 동작하지만, 오프라인 캐시는 `http://localhost`나 `https` 주소에서만 켜집니다.
